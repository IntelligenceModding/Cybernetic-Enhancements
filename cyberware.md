# Cyberware Reference

This file maps every cyberware entry in the mod to its closest Cyberpunk 2077 counterpart and summarizes what that counterpart does in Cyberpunk 2077.

Notes:
- If the mod name is not the exact in-game name, the `CP2077 counterpart` column shows the closest family or named implant I used.
- `Chipware Socket` entries are mod abstractions. Cyberpunk 2077 does not expose them as named ripperdoc cyberware on the 2.0 cyberware list the way the mod does.
- Descriptions below are concise gameplay summaries, not full stat sheets.

## Frontal Cortex

| Mod cyberware | CP2077 counterpart | What it does in Cyberpunk 2077 |
| --- | --- | --- |
| Camillo RAM Manager | Camillo RAM Manager | Instantly restores a chunk of RAM when your available RAM falls low, then goes on cooldown. |
| RAM Reallocator | RAM Reallocator | A stronger iconic Camillo-style implant that restores an even larger chunk of RAM when you bottom out on RAM. |
| Bioconductor | Bioconductor | Lets quickhacks crit, boosts quickhack crit chance, and trades away some Max RAM. |
| COX-2 Cybersomatic Optimizer | COX-2 Cybersomatic Optimizer | The iconic Bioconductor variant: it massively increases quickhack crit chance at the cost of Max RAM. |
| Ex-Disk | Ex-Disk | Raises Max RAM and improves quickhack upload speed. |
| Kerenzikov Boost System | Kerenzikov Boost System | Enhances Kerenzikov so ranged attacks cost no stamina while it is active and time slows harder relative to enemies. |
| Mechatronic Core | Mechatronic Core | Increases damage against drones, robots, mechs, and turrets, and also adds some Max RAM. |
| Memory Boost | Memory Boost | Refunds RAM whenever you neutralize an enemy. |
| Newton Module | Newton Module | Instantly trims a small amount off all cyberware cooldowns whenever you neutralize an enemy. |
| Axolotl | Axolotl | The iconic Newton-style implant; each neutralization cuts a much larger chunk off all cyberware cooldowns. |
| Quantum Tuner | Quantum Tuner | When another cyberware implant is fully spent, it can instantly refresh that implant's cooldown, and it also passively lowers cooldown time on your other cyberware. |
| RAM Upgrade | RAM Upgrade | Improves RAM regeneration and adds Max RAM. |
| Self-ICE | Self-ICE | Automatically negates an incoming enemy quickhack, then recharges over time. |
| Chipware Socket | No direct named 2077 counterpart | Mod abstraction for skill-chip or shard capacity; Cyberpunk 2077 uses chipware and shard interfaces, but not as this exact named installable cyberware item. |
| Chipware Socket Mk.2 | No direct named 2077 counterpart | Same concept as above: a mod-side expansion of chipware capacity rather than a named CP2077 ripperdoc implant. |
| Chipware Socket Mk.3 | No direct named 2077 counterpart | Same concept as above: a high-end mod abstraction for extra chipware capacity rather than a named CP2077 menu item. |
